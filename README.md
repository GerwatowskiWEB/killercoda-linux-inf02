# Scenariusze Killercoda: polecenia Linux (INF.02)

Scenariusze po polsku do nauki poleceń Linux na Ubuntu Server. Każdy folder to osobny scenariusz.

## Scenariusze INF.11 (cyberbezpieczeństwo)

Osiem laboratoriów (foldery `inf11-*`): Linux ACL, utwardzanie SSH, UFW, analiza logów, diagnostyka TCP/IP, OpenSSL PKI, bezpieczeństwo SQL, Python (analiza logowań). To materiały projektowe, które przed użyciem z uczniami trzeba przejść na Killercoda (Docker, UFW w kontenerze, systemd, apt, obraz MariaDB).
