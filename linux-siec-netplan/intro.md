# Netplan: konfiguracja sieci w Ubuntu Server (YAML)

W Ubuntu Server sieć konfiguruje się plikami YAML w katalogu `/etc/netplan/`. W tym scenariuszu napiszesz taki plik, zastosujesz go i znajdziesz błąd w cudzej konfiguracji.

**Ważne:** ćwiczysz wyłącznie na interfejsach wirtualnych `dummy0` i `dummy1`. Nie zmieniaj istniejących plików w `/etc/netplan/` i nie ruszaj głównej karty sieciowej, bo stracisz połączenie z terminalem.

Poczekaj, aż skończy się przygotowanie środowiska (kilkanaście sekund).
