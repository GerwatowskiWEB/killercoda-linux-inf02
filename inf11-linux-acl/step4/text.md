# Krok 4. Zweryfikuj odmowę nieuprawnionego dostępu

Wykonaj testy dostępu z kont `anna`, `bartek` i `gosc` (`sudo -u ...`). Następnie zapisz w `~/inf11-acl-wnioski.txt` trzy linie `anna=rw`, `bartek=r`, `gosc=brak`.

Czy użytkownik `gosc` może odczytać raport? Uzasadnij, uwzględniając uprawnienia katalogów.
